Проекты в продакшене

ImpulSpeak

Голосовая образовательная платформа с AI-репетитором Светланой (английский и казахский курсы).

FastAPIGemini APIWhisperedge-ttsSQLiteVoskJavaScriptLinuxCaddyGitHub ActionsHetzner

Задача

  • Дать человеку практику живого разговора на иностранном языке без репетитора.
  • Объединить распознавание речи, ИИ-диалог и естественную озвучку в едином потоковом конвейере.
  • Обеспечить качественное распознавание казахской речи, с которой не справляются мировые модели.

Решение

  • Backend-архитектура с нуля на FastAPI с REST API для голосовых сценариев.
  • Vosk (офлайн STT) для казахского языка, Whisper для английского, Gemini для логики диалога, edge-tts для голоса.
  • Хранение профилей и истории прогресса в SQLite с ежечасными бэкапами.
  • Клиентский PWA-интерфейс с поддержкой добавления на экран смартфонов iOS и Android.

Результат

  • Работающий сервис impulspeak.com: интерактивные сценарии (аэропорт, банк, собеседование).
  • Перенос с Google Cloud на Hetzner: серверные расходы сокращены в 4 раза (с ~$20 до ~€4/мес) при 100% аптайме.
  • Сравнение моделей: казахская модель Vosk распознала 9 из 9 фраз, в то время как облачный Whisper дал 0 из 9.
  • Двойной мониторинг: локальный сторож раз в 5 минут с автовосстановлением и ботом в Telegram + проверка на GitHub Actions.

AI Assistant v1.0 — Автономная агентная система

Персональный центр управления проектами, веб-разведки (Deep Research) и биржевой аналитики KASE с мобильным PWA-доступом.

Python 3.14FastAPI / HTTP ServerGemini API (Multi-Model Fallback)SQLitePWACloudflare Tunnel (HTTP/2)OpenSSHDeep Research

Задача

  • Создать автономного ИИ-ассистента с долговременной памятью и строгой изоляцией данных ($0 бюджет).
  • Обеспечить защищённый доступ со смартфона через мобильный интернет (4G/5G) без выделенного белого IP.
  • Автоматизировать ежедневный утренний аудит проектов, проверку сайта школы и мониторинг котировок акций KASE.

Решение

  • 3-контурная матрица безопасности (Read-Only ядро, Safe Workspace, версионирование и авто-бэкапы в SQLite).
  • Двухканальное облачное туннелирование: Cloudflare Quick Tunnel (HTTP/2) + OpenSSH (Localhost.run) с QR-кодом для телефона.
  • PWA-дашборд с защитой по сессионному ПИН-коду и автономной установкой на экран смартфона как нативное приложение.
  • Модуль Deep Research: бесплатный сбор веб-источников (DuckDuckGo + Wikipedia API) с двойной верификацией фактов (Double Check).

Результат

  • 3-уровневый интеллектуальный маршрутизатор: локальный контур Level 0 экономит до 60% квот API.
  • Автоматический Утренний брифинг: параллельный опрос 7 эмитентов биржи KASE (KZTO, KSPI, HSBK, KEGC, GB_ALTN, MMGZp, AIRA) за 2.5 секунды.
  • Полное покрытие сквозными тестами: режим самопроверки [11/11 OK] подтверждает отказоустойчивость всех узлов.

Система автоматической сводной аналитики продаж (B2B)

Консолидация разрозненных каналов торговли (офлайн-точка, WhatsApp, Instagram, звонки) в единый управленческий дашборд.

PythonFastAPITelegram Bot APIWhatsApp ParserPostgreSQL / SQLiteExcel / Google Sheets

Задача

  • Ручной сбор и сверка заявок из мессенджеров, социальных сетей и кассы отнимали у руководителя до 2 часов ежедневно.
  • Человеческий фактор приводил к потере заказов и расхождениям в кассовой отчётности.

Решение

  • Разработан конвейер агрегации: боты и фоновые парсеры перехватывают входящие заявки и нормализуют позиции.
  • Автоматическая синхронизация с базой данных и выгрузка в наглядные сводки в Telegram и Excel.

Результат

  • Время подготовки ежедневной сводки для собственника сократилось с 2 часов до 30 секунд.
  • Исключена потеря заказов, реализован мгновенный расчёт чистой прибыли, маржинальности и остатков.
