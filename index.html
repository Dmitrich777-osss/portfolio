Флагманский проект

ImpulSpeak

Платформа для изучения языков с ИИ-репетитором: можно говорить голосом, получать ответы и разбор от ИИ.

FastAPIGemini APIWhisperedge-ttsSQLite

Задача

  • Дать человеку практику живого разговора на иностранном языке без репетитора
  • Объединить распознавание речи, ИИ-диалог и озвучку в одном сервисе

Решение

  • Backend-архитектура с нуля на FastAPI
  • REST API для интеграции с AI-сервисами
  • Whisper — речь в текст, Gemini — диалог, edge-tts — голос
  • Хранение данных пользователей в SQLite

Результат

  • Рабочий продукт, доведённый до запуска
  • Полный цикл: от голоса пользователя до голосового ответа ИИ
